# prompts/

Reusable AI prompts for working with this template.

| File             | Use it when…                                                        |
| :--------------- | :------------------------------------------------------------------ |
| `seo-update.md`  | You start a new project from this template and need to configure all baseline SEO (domain, titles, descriptions, sitemap, structured data, OG image). Paste it into your AI assistant, fill in the **Project brief** at the top, and let it drive the changes. |

These are living documents — refine them as the template evolves so the next
project inherits the improvements.
